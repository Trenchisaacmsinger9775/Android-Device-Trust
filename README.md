Android-Device-Trust was mainly built as an emulator and modified device detector based on my two blog posts, [Catching Fraud on Android with Machine Learning](https://reveny.me/posts/catching-fraud-on-android-with-machine-learning/) and [Detecting Android Emulators the Right Way](https://reveny.me/posts/detecting-android-emulators-the-right-way/).

It works by collecting device trust signals, sending them to a backend for server side validation, and returning a device status.

This is similar to what social media and many other apps use. It combines device signals and various fingerprints to determine whether a device is clean or whether it has been involved in repeated fraud.

## Features
- Server-side device trust evaluation
- Remote key attestation
- App package and signing certificate validation
- Emulator and modified environment checks
- Device recognition across app launches
- Minimal Material Design 3 demo UI
