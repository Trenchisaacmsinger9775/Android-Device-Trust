## 🛠️ How It Works (Simple Explanation)

When you run Android-Device-Trust, it performs several checks on your connected Android device. Here is what happens behind the scenes:

1. **Hardware Check:** It reads the device's processor information, serial numbers, and hardware IDs.
2. **Software Check:** It examines the operating system version and build numbers.
3. **Sensor Check:** Real devices have physical sensors. The tool verifies that sensors like accelerometers and gyroscopes respond correctly.
4. **Network Check:** It looks at network interfaces and MAC addresses.
5. **Comparison:** All this data is compared against known patterns of real devices and emulators.

The entire process takes about 5 seconds. You see the result immediately.
